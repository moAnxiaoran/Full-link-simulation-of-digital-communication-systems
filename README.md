# 数字通信系统全链路仿真平台

一个带图形界面（GUI）的数字通信全链路仿真平台。从比特生成到误码统计的每一个环节都在界面上可见、可点、可改参数，不需要写代码、不需要命令行，改完参数点一下就能看到新结果。

## 一、平台能做什么

完整链路按下面 8 个模块贯通，左侧流程图与之一一对应：

```
① 比特生成 → ② 信道编码 → ③ 调制成形 → ④ 信道
      → ⑤ 匹配滤波 → ⑥ 采样判决 → ⑦ 解码 → ⑧ 误码统计
```

- **信源**：随机比特（可设数量、种子）、手动输入比特串、全 0、全 1
- **信道编码**：无编码、重复码 (3,1)、汉明码 (7,4)、卷积码 (2,1,3)、BCH (15,7)
- **调制与成形**：BPSK / QPSK；根升余弦 RRC、升余弦 RC、矩形脉冲；可调过采样率、滚降系数、滤波器跨度
- **信道**：AWGN 高斯白噪声，可设 Eb/N0 和噪声种子，也可关闭噪声走理想信道
- **位同步**：理想最佳采样，或早迟门（Early-Late Gate）定时跟踪，环路参数可调
- **误码统计**：编码域 BER、解码后信息 BER、误比特数、理论 BER、定时抖动
- **BER 扫描**：一次跑一条 Eb/N0 曲线，多种编码方案对比，支持固定符号数和目标错误数自适应
- 另附**基带码型分析**（NRZ / Manchester / AMI / HDB3 的波形、眼图、功率谱）和 **PCM 脉冲编码调制**（抽样、量化、重建、A 律）两个独立选项卡

## 三、运行环境与启动

### 环境要求

- Python 3.9 及以上（需带完整 tkinter，官方安装包默认勾选）
- 依赖包：`numpy`、`scipy`、`matplotlib`、`pillow`

安装依赖：

```
pip install numpy scipy matplotlib pillow
```

### 启动方式

**方式一（推荐）**：双击 `启动仿真平台.bat`。脚本会优先使用本机已验证可用的解释器；找不到时再到系统 PATH 里逐个测试哪个 Python 的 Tk 运行库真正可用，选好后自动启动。

**方式二**：在本目录打开命令行执行：

```
python run_platform.py
```

> 注意：如果 `python` 指向的是某些精简/内嵌环境，可能出现 `Can't find usable init.tcl` 之类的报错，说明该解释器缺 Tcl 运行库，换一个完整安装的 Python 即可。

## 四、界面怎么用

### 顶部按钮

| 按钮 | 作用 |
| --- | --- |
| 全链路运行 | 从①到⑧把整条链路跑一遍 |
| 单步运行 | 只跑当前流程图选中的那一个模块 |
| BER 扫描 | 跳到 BER 扫描选项卡 |
| 保存结果 | 把配置、数据、日志、BER 表存到 `platform_results/` |
| 导入配置 / 导出配置 | 用 JSON 文件保存/恢复整套参数 |
| 恢复默认 | 所有参数还原为出厂值 |
| 运行日志 | 查看每一步的执行记录 |

### 左侧流程图

8 个模块框，点哪个就跳到哪个模块的选项卡；当前正在跑或参数已变更的模块会有颜色提示。

### 选项卡（共 13 个）

- **总览**：关键指标卡片，一眼看清本次运行结果
- **①～⑧ 模块页**：上半部分是该模块的参数控件，下半部分是对应图表（波形、星座、眼图、功率谱、噪声分布、采样点、解码对比等），图表带 matplotlib 导航工具栏，可以缩放、平移、另存
- **BER 扫描**：设置 Eb/N0 范围、步长、勾选编码方案后点"运行 BER 扫描"，上半部分出半对数对比曲线，下半部分出数据表
- **基带码型分析**：选码型、给比特串、设采样点，时域波形/眼图/功率谱立即刷新
- **PCM 脉冲编码调制**：设抽样率、量化位数等，看抽样—量化—重建全过程和 SNR 理论曲线

### 改参数后会发生什么

任何参数改动都会让它**下游的模块自动标记为"脏"**（流程图上能看到状态变化）。比如改了调制方式，后面的信道、滤波、判决、解码结果都失效，需要重新运行；而上游已经算好的结果不受影响，不用重算。

## 五、结果可复现是怎么保证的

1. 所有参数集中在一份配置里，点"导出配置"即得到一个 JSON 文件；把这个 JSON 发给别人，对方"导入配置"后运行，结果与你完全一致。
2. 信源和噪声都由**随机种子**控制（默认信源种子 42、噪声种子 2026），相同种子产生完全相同的随机序列。
3. 每次"保存结果"都会额外存一份当时的配置快照，任何一次历史结果都能凭快照原样复现。

## 六、结果保存到哪里、长什么样

点"保存结果"后，在 `platform_results/` 下生成（时间戳区分每次运行）：

| 文件 | 内容 |
| --- | --- |
| `config_snapshot_*.json` | 本次运行的完整配置快照 |
| `chain_data_*.npz` | 全链路各节点的数组数据（比特、波形、采样值等），可用 numpy 读取 |
| `ber_scan_*.csv` | BER 扫描数据表（Excel 可直接打开，UTF-8 BOM 不乱码） |
| `run_log_*.txt` | 运行日志 |

读取 npz 示例：

```python
import numpy as np
d = np.load("chain_data_xxxxxx.npz")
print(d.files)          # 查看里面有哪些数组
print(d["info_bits"])   # 取出信源比特
```

## 七、与原有仿真文件的关系

本平台是在不改动原有文件的前提下，把它们的算法整合、重构进 `comm_platform/` 包，对应关系如下：

| 原有文件 | 整合进平台的位置 |
| --- | --- |
| `baseband_codes_simulation.py`（基带四码型） | `blocks/linecodes.py` + 基带码型分析选项卡 |
| `channel_coding_comparison.py`（五种编码方案） | `blocks/channel_codes.py` + 信道编码/解码/BER 扫描 |
| `qpsk_awgn_demo.py`（QPSK 噪声演示） | `blocks/modulation.py`、`blocks/metrics.py` + 调制/信道选项卡 |
| `early_late_gate_sim.py`（早迟门） | `blocks/timing.py` + 采样判决选项卡 |
| `pcm_simulation.py`（PCM） | `blocks/pcm.py` + PCM 选项卡 |

原来的脚本依然可以单独运行，两者互不影响。

## 八、关键建模约定（便于核对理论值）

- 三种脉冲统一做**单位能量归一化**（脉冲系数平方和为 1），发送、接收各滤波一次；收发总响应在整数符号点过零（无码间串扰），总链路延迟恰为一个滤波器跨度。
- 发送符号能量固定为 Es = 1。BPSK 下 N0 = 1/(R·EbN0)，QPSK 下 N0 = 1/(2R·EbN0)，其中 R 为编码码率；每个实数维度叠加 N(0, N0/2) 的高斯噪声。
- 信息比特长度不是编码分组整数倍时自动补零（补零位数有记录，解码后剔除），不影响 BER 统计口径。
- BER 扫描走符号级快速路径，与波形级逐采样点的统计在数学上等效，结果一致但速度快得多。

默认参数下的验证结果（部分）：BPSK 无编码 8 dB 实测 BER 约 2×10⁻⁴，理论值 1.91×10⁻⁴；0 dB 大样本实测 7.83×10⁻²，理论 7.87×10⁻²，吻合良好。高 SNR 点由于错误事件稀少，蒙特卡洛结果会有正常波动，想更平稳就增大比特数或改用目标错误数自适应模式。

## 九、常见问题

**Q：双击 bat 闪一下就没了？**
A：bat 已做错误暂停，正常情况下会停住显示原因。多数是没装依赖或 Python 缺 tkinter，按第三节装一遍依赖、换完整 Python 即可。

**Q：图表里中文变成方框？**
A：平台默认使用微软雅黑，正常 Windows 都有；若系统精简掉了该字体，装一个中文字体即可，不影响计算。

**Q：BER 在高信噪比时变成 0 或上下跳？**
A：发送的比特数不够、错误事件太少。把信源比特数调大，或 BER 扫描时勾选"按目标错误数自适应"。

**Q：想批量跑而不是点界面？**
A：引擎本身可以脱离 GUI 调用，`from comm_platform.config import SimConfig, save_config`、`from comm_platform.engine import Engine`，用脚本构造 `SimConfig` 后调 `Engine(cfg).run_all()` 即可，界面和脚本共用同一套引擎。
